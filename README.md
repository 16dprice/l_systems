A viewer for L systems (https://en.wikipedia.org/wiki/L-system)

Clone and run with `cargo run --release`.
- Zoom in/out with `i/o` on the keyboard
- Adjust iterations more/less with `]/[` on the keyboard
- Navigate on screen with `WASD`
- Change angle for L system rendering using left and right arrow keys
